# 跨设备演示

项目位置：`apple_ai/ImageBridgeDemo/`，包含独立 iOS 和 HarmonyOS 工程。

当前功能：后台 App Intent 批量传图、消息群发、HMOS 消息追加列表、系统通知、短时后台接收，以及用户确认后保存图库并打开图库。相机自动化动作已注册，但导入文件及相机完整自动触发链路仍待验证。

构建缓存、日志、设备清单、签名密钥/证书和已签名快捷指令仅保留在本机，不上传 Git。`*.unsigned.shortcut` 是模板，必须先用 macOS `shortcuts sign` 签名才能导入；下文旧测试日志路径只在原开发机器可用。以下历史记录以靠后的更新为准。

同一目录包含 iOS 和 HarmonyOS 两份独立工程。两个应用均为「演示列表 → 单个演示」结构，界面仅保留入口、操作和状态。

| 演示入口 | iOS 快捷指令动作 | 输入 | 华为端行为 |
| --- | --- | --- | --- |
| 图片分享 | 发送到我的华为手机 | 1～20 张图片 | 逐张保存，系统文件预览最后一张 |
| 消息分享 | 分享消息给我的华为手机 | 文本 | 弹框，标题「收到来自iPhone的通知」，正文为原文 |

## 使用

两台手机连接同一 Wi-Fi，打开华为端应用。接收服务随应用启动，切换首页、图片页、消息页不会关闭服务。

iPhone 应用内可分别进入图片分享或消息分享。快捷指令中可使用「选择照片 → 发送到我的华为手机」或「文本 → 分享消息给我的华为手机」。两个 Intent 都声明 `.background`，不请求打开 iOS 应用。只有多个接收端时需要选择目标。

图片默认支持批量选择，按选择顺序发送。华为将图片保存在应用私有目录 `files/received-images/`，整批收完只打开最后一张的系统文件预览；图片页可再次打开最后一张。当前未写入公共相册，卸载应用会删除这些文件。

### 照片共享菜单

工程通过 `AppShortcutsProvider` / `AppShortcut` 注册图片动作，与 apple_ai 的短信分类动作相同。出现在照片共享菜单底部，还需要快捷指令启用「在共享表单中显示」并接收图片。

在 iPhone 打开并添加 `iOS/Shortcuts/发送到我的华为手机.shortcut`（已签名，已配置接收图片并将「快捷指令输入」传给图片动作），随后在照片中多选 → 分享 → 发送到我的华为手机。已在 Mac 快捷指令中导入，确认「从共享表单接收图像」；Mac 未安装此 iOS 应用，动作显示未知，尚待 iPhone 识别与共享菜单验证。如果没有同步到 iPhone，需在手机打开该文件添加。

消息弹框属于华为应用内弹框，需要接收应用前台运行；不是系统通知，也不唤醒已退出的应用。长文本可滚动查看，换行、空格、中文和 emoji 按原文保留。新消息到来先关闭旧弹框，再显示新的原文。弹框打开即返回成功，不等待用户点击「确定」。

## 工程

- `iOS/ImageBridge.xcodeproj`：SwiftUI 导航、两个 App Intent、Bonjour/TCP 发送。
- `HarmonyOS/`：DevEco Stage 工程、ArkTS 接收、两级界面和模态弹框。
- `docs/demo2-message.md`：第二个演示的协议与范围。

参考 Storm/Breeze 的 mDNS 自动发现与 TCP 四字节小端长度分帧方式，未引入 Rust、CRDT、拓扑或视频模块；这不是完整 STORM 协议节点。

| 协议 | 图片 | 文本 |
| --- | --- | --- |
| Bonjour 服务 | `_imgbridge._tcp` | `_msgbridge._tcp` |
| TCP 端口 | 22856 | 22857 |
| 内容 | IBAT + uint32 LE 张数，然后逐张 uint32 LE 长度 + JPEG | uint32 LE 长度 + UTF-8 原文 |
| 上限 | 20张，每张20 MiB、整批100 MiB，最长边2048像素 | 65536 UTF-8 字节，空文本拒绝 |
| 成功 ACK | 每张保存后0；最后一张等待预览调用成功后0 | 弹框打开后0 |

发现结果稳定350毫秒后连接，最多查找5秒；每图发送超时30秒，最后一张45秒，包含系统预览最多10秒的等待。华为立即发布服务并由系统响应 mDNS 查询。文本不截断、不trim、不做Unicode正规化，非法UTF-8拒绝。两个演示使用独立监听器。批量图片使用新协议，两端应一起更新；消息协议保持不变。最后一张已保存但预览失败返回ACK2，保留文件并提示失败，不静默重发。

图片 Intent 保留 `LongRunningIntent`、进度和取消能力。消息 Intent 是普通后台 `AppIntent`。前台按钮与系统 Intent 共享传输代码；前台调用证据不能代替系统快捷指令证据。

## 构建安装

iOS 命令和证据见 `iOS/README.md`。

```sh
cd HarmonyOS
./scripts/build.sh
python3 scripts/sign-debug.py 4YM0124C06000107
/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc \
  -t 4YM0124C06000107 install signing/ImageBridge-signed.hap
/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc \
  -t 4YM0124C06000107 shell aa start -a EntryAbility -b com.rain.imagebridge
```

该签名脚本使用 SDK OpenHarmony 测试身份，适用于当前开发机型；零售 HarmonyOS 设备应使用 DevEco 的正常签名配置。脚本不改变验签设置。签名材料和构建输出位于忽略目录。

## 短时后台与图库跳转

HMOS EntryAbility 在 onBackground 申请一份 requestSuspendDelay，覆盖图片、消息监听；onForeground/onDestroy/到期回调释放，不循环续期。0107真机日志确认获批 actualDelayTime=180000 毫秒，这不是固定时长承诺，配额由系统决定。后台图片先保存私有目录，图库确认需回到前台点击保存；后台消息以系统通知发布成功为ACK条件，不打开隐藏弹框。短时任务不会唤醒已退出的应用。

图库保存成功后改为 startAbility 打开 com.huawei.hmos.photos.MainAbility（本机安装信息验证的入口），不定位私有相册路由。已在0107真机点击同一 openGallery 方法确认进入 Photos/Albums/Highlights 主界面；保存后整链路未新增真机验证。其他设备若入口不同会提示手动打开。最新版当前仅更新0107。

图库自动保存更新：移除「保存到图库」按钮。前台收完自动发起系统保存确认；后台收完标记待处理，onForeground 自动继续。用户取消不会在本次恢复回调中反复弹窗；新批次或重新启动应用可再次处理保留文件。保存确认期间新到的批次排队处理。当前安装更新到0107，其他设备待连接更新。
